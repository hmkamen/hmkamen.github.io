# hmkamen.github.io

Personal academic website for Hannah Kamen.

## Publish on GitHub Pages
1. On GitHub, create a new **public** repository named exactly `hmkamen.github.io`.
2. Upload everything in this folder (index.html, style.css, README.md, and the files/ folder) with "Add file → Upload files", then commit.
3. Go to Settings → Pages. Under "Build and deployment", choose "Deploy from a branch", then `main` / `(root)`, and save.
4. After 1–2 minutes the site is live at https://hmkamen.github.io

## Updating
- New JMP draft: replace `files/Kamen_JMP.pdf`, keeping the same filename so existing links still work.
- New CV: replace `files/Kamen_CV.pdf`.
- Headshot: add `files/headshot.jpg`. It replaces the "HK" placeholder automatically.
